# Contributing

Thank you for wanting to help.

## During the beta: bug reports and ideas, not code

We welcome:

- **bug reports**: open an issue at <https://github.com/Leonfinn/Boss_Man/issues>
- **ideas and questions**: start a discussion at <https://github.com/Leonfinn/Boss_Man/discussions>

We do not take pull requests during the beta. Boss Man's own agents write and review every change under one set of checks, and we cannot yet give outside code the careful review it deserves.

If you have a fix in mind, describe it in an issue. That helps us just as much.

Security problems go through GitHub's private reporting form, not in an issue. See [SECURITY.md](SECURITY.md).

We will look at this again after the beta.
