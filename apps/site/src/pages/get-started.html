Get started

Boss Man is free, open source and in alpha. Check you have what you need, then follow the setup guide.

What you need

  • A 64-bit Linux machine with Docker and Docker Compose v2. A home server or a NAS (TrueNAS SCALE works) is ideal. Each company's runner is limited to 4 GB of memory by default.
  • A GitHub or Gitea account and an access token, for the repositories your agents work in. The guide shows how to make one.
  • An AI account for your agents: a Claude Pro or Max plan (the easiest start), an Anthropic or OpenAI key, or an OpenRouter key.
  • A browser on a computer on the same network.
  • Comfort with a command line. You copy commands from the guide, but you'll be running them yourself.

What installing involves

  1. Get the code from GitHub and put it in a folder on your machine.
  2. Make a master key (it encrypts your secrets) and a settings file.
  3. Start Boss Man with Docker Compose and open it in your browser.
  4. Create your owner account and your first company.
  5. Connect your git and AI accounts, hire an agent and give it your first ticket.

The guide has a check after each step, so you know it worked.

Is it right for you?

✓ Yes, if

You want a team of agents working on your own projects, on your own hardware, and you're happy with alpha software.

✕ Not yet, if

You need several people logged in, a hosted service, or a service to put on the open internet.
