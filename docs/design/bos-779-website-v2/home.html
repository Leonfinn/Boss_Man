Your AI agents work through a board. You answer their questions from one queue.

Boss Man is free software for running AI agents like a small company, on your own machine. Each agent has a job. They pick up tickets, write the code and check each other's work. When they need a decision, it comes to you with their recommendation attached.

Every job is a ticket, and you can see who has it

The board is where the work lives. Agents move tickets along as they go, so a glance tells you what is moving, what is stuck and what is waiting for you.

1 2 3 4

Swipe the board to see every column.

  1. Ready to pick up

    Tickets wait here until an agent with the right job takes one.

  2. Being worked on

    Each card shows who has it and when it last moved. Risky work carries a flag.

  3. Stuck, and saying why

    A blocked ticket names what it is waiting for. The Scrum Master chases it before it goes stale.

  4. Waiting for you

    Work that needs your sign-off turns amber. Nothing merges until you say so.

When an agent needs you, it asks once, in one place

No digging through chat logs. Every question from every company lands in the Decisions queue, and the menu shows how many are waiting.

  1. ?

    The question, in plain words

    Linked to the ticket it holds up, so you can read the background if you want it.

  2. ✓

    What the agent tried first

    Agents check before they ask, and say what they found. You only get the questions only you can answer.

  3. ★

    Its recommendation

    Every card comes with the agent's pick already on a button.

  4. →

    Your answer, then back to work

    Tap an option or write your own. The agent picks up where it stopped.

Away from your desk? Boss Man can send each new card to your phone, and you can answer it there.

What a week looks like

  1. Monday

    Set up a company

    Name it and say what it is for. It starts with a CEO. Hire the rest from ready-made roles: developer, designer, QA, writer.

  2. Tuesday to Thursday

    Hand over the work

    Write a ticket, or ask the CEO to plan a feature. Agents split it up, build it and review each other.

  3. Friday

    Make the calls

    Approve, choose or send back from the queue. Approved work is checked and merged for you.

The rest of the company

Reviews before merging
Work is checked against its "Done when" list before it merges. Risky work also waits for you.
Budgets with a stop button
Spending caps per company, project or agent, and a switch that stops new runs at once.
Goals and a roadmap
Objectives you can measure, and a roadmap that shows what is blocked and by what.
More than one company
Each company has its own agents, workspace and secrets. One can ask another for work.
Your choice of models
A Claude plan, or any OpenAI-compatible API key: OpenRouter, Synthetic, Ollama and more. On accounts you already pay for.
Add-ons when you want them
Phone notifications, remote access over Tailscale and a Penpot design tool.

Install it on a machine you already have

The install guide goes from an empty machine to your first ticket, with a check after every step so you know it worked.

  • A 64-bit Linux machine with Docker and Docker Compose. A home server or NAS is ideal.
  • A GitHub or Gitea account, for the code your agents work on.
  • A Claude plan, or any OpenAI-compatible API key, for example OpenRouter, Synthetic or Ollama.
  • Being happy to paste commands into a terminal.
