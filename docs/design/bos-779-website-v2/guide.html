Write your first ticket

A ticket is one piece of work for an agent. This guide gives your CEO its first job and shows you where to watch it happen.

About 5 minutes. You need Boss Man installed and a company set up.

Before you start

Check the runner says Connected in Settings, then Server and runner. Without it, agents can't start.

1. Add the ticket

  1. Open Projects in the side menu, then your project.
  2. Choose Add task.
  3. Type a Title, for example "Read the repo and propose a roadmap".
  4. Pick your CEO under Assign to.
  5. Choose Add and start. To add it without starting it, choose Add to backlog instead.

✓ It worked if the ticket shows on the board and the page says "Added".

2. Watch it run

Within a minute or two the CEO picks the ticket up and it moves to In progress. Open the ticket to follow what the agent is doing and talk to it.

  • Runs lists every agent run, running and recent.
  • Decisions is where agents ask you things: a plan to approve, a review, a question.
  • Notifications shows anything else that needs a look.

3. Answer the first question

Most first tickets end with a question for you. It shows in Decisions with the agent's recommendation on a button.

If nothing happens

The ticket stays in Ready
The agent may be paused. Open Agents and choose Start on its row.
The runner says Disconnected
Restart it from Settings, then Server and runner. The install guide's troubleshooting part has more.
