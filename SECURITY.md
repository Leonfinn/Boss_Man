# Security

This page is for you if you think you have found a security problem in Boss Man.

## Report it privately

Email **`<security email>`** <!-- PLACEHOLDER: the owner's address goes here (BOS-960). Do not publish this file until it is filled in. -->

Please do not open a public GitHub issue for a security problem. Other people's servers could be attacked before a fix is out.

When the repository is public, we will switch to GitHub's private reporting form (the **Report a vulnerability** button on the Security tab) and update this page.

## What to put in your email

- what the problem is and what an attacker could do with it
- the steps to make it happen
- the Boss Man version (the commit) you tested
- whether you have told anyone else

## Which versions we fix

Boss Man is in beta. We fix the latest version on the `main` branch only. Update to it before you report, if you can.
