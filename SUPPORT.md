# Getting help

This page is for you if Boss Man is not doing what you expect and you want help.

- **Something is broken?** Open an issue: <https://github.com/Leonfinn/Boss_Man/issues>. Say which step of which guide you were on, what you expected, and what happened instead.
- **A question or an idea?** Start a discussion: <https://github.com/Leonfinn/Boss_Man/discussions>.
- **A security problem?** Do not post it in public. See [SECURITY.md](SECURITY.md).

Before you ask, check the install guide, [docs/00-first-time-install.md](docs/00-first-time-install.md). Many problems are covered there.

There is no chat server or phone support. Boss Man is a small project, so replies can take a few days.
